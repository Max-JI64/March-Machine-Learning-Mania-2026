# March Machine Learning Mania - 모델 학습 및 발전 자동화 가이드 (AI Agent 지침서)

이 문서는 사용자가 "다음 단계의 모델 학습을 진행해줘" 또는 이와 유사한 요청을 했을 때, AI 에이전트가 어떤 흐름으로 작업을 수행해야 하는지 명시한 작업 지침서입니다. AI는 매 요청마다 이 문서를 참고하여 자율적이고 점진적인 모델 발전 파이프라인을 실행해야 합니다.

모든 답변은 항상 한국어로 답할 것.

## 🔄 전체 작업 처리 흐름 (Workflow)

### 1단계: 기존 학습 기록 및 현재 상태 파악
- 가장 먼저 `Analysis/analysis_log.md` 파일을 읽어서 지금까지 어떤 모델(XGBoost, LightGBM, CatBoost 등)이 시도되었고, 각 튜닝 버전(V1, V2, 등)의 **최적 하이퍼파라미터**와 **성능(Brier Score)**이 어떠했는지 분석합니다.
- 파일 하단의 **"향후 과제"** 또는 **"결론 및 향후 전략"** 섹션을 확인하여 이번 단계에서 어떤 기술적 시도(예: 앙상블, 모델 추가, 피처 제어, 정규화 강화 등)를 해야 하는지 결정합니다.

### 2단계: 다음 단계의 학습 스크립트 작성 및 실행
- 파악된 과제를 바탕으로 새로운 학습 파이프라인 코드 스크립트를 작성합니다.
- **파일 명명 규칙:** 반드시 해당 **작업을 수행하는 당일의 날짜**를 기준으로 `YY.MM.DD_[학습방법]_[버전].py` 형태로 `Analysis` 폴더 안에 생성합니다.
  - *예시: 26.03.10_Ensemble_V1.py, 26.03.10_CatBoost_V1.py*
- 대회 평가 지표인 **Brier Score (MSE)** 및 모델 일반화 성능을 위한 **시간 기반 롤링 교차 검증 (Time-based Rolling Holdout)** 로직이 스크립트에 철저하게 반영되어야 합니다.
- 스크립트를 실행하여 모델을 학습시키고 연도별 검증 성능을 추출합니다. (단, 사용자가 실행 전에 확인을 원할 경우 코드를 먼저 제공하고 진행합니다.)

### 3단계: 결과 기록 및 분석 (`analysis_log.md` 업데이트)
- 모델 평가가 완료되면, 그 결과를 반환받아 `Analysis/analysis_log.md`의 새로운 섹션으로 기입합니다.
- 다음 항목이 반드시 포함되어야 합니다:
  1. **실험 제목**: (예: `### C. Ensemble V1 (XGB+LGB Soft Blending) — 완료`)
  2. **실행 파일명 및 핵심 파라미터**: 사용된 가중치나 새로 발견된 하이퍼파라미터 등
  3. **연도별 검증 결과표 (Brier Score)**: 직전에 최고 성능을 냈던 모델(Baseline)열을 옆에 붙이고, 새 모델과 비교(`증감치`)하여 직관적으로 향상/하락을 파악할 수 있도록 표를 구성합니다.
  4. **결과의 해석 및 분석**: 수치적 변화를 토대로 "특정 연도(이변이 많은 해)에서 방어력이 좋아졌다", "전체 평균 성능은 올랐으나 과적합 징후가 있다"와 같이 분석 내용을 텍스트로 추가합니다.

### 4단계: 다음 모델링 방향 (Next Step) 수립
- 방금 기록한 결과를 바탕으로 문서 최하단의 **"향후 과제"** 또는 **"Next Step"**을 갱신합니다.
- 예: "가중 평균 앙상블의 효과가 미미했으므로 Logistic Regression을 활용한 Stacking으로 변경해본다", "성능이 정체되었으니 노이즈 피처를 줄이거나 파생 변수를 새롭게 고안한다" 등, 다음 번 호출 시 AI 스스로 무엇을 해야 할지 알 수 있도록 구체적으로 메모해야 합니다.

## 💡 모델 점진적 발전 전략 가이드
AI는 특별한 외부 지시가 없다면 아래의 로드맵을 참고하여 모델을 단계적으로 발전시킵니다.
1. **단일 모델 최적화**: XGBoost, LightGBM, CatBoost인 경우 각각의 하이퍼파라미터 범위를 좁혀가며 세밀 튜닝 (Tree depth 감소, L1/L2 Regularization 강화 등 일반화 목적 우선).
2. **데이터 처리/피처 조정**: Data Augmentation 강도 조절 (Noise scale 탐색), 타임라인 Decay 가중치 조절, 무의미한 피처 삭제.
3. **Ensemble & Blending**: 강력한 베이스 모델(예: 최적화된 XGB, LGBM)들의 예측 확률값 블렌딩. 단순 평균에서 출발하여 최적 가중치 탐색(Weighted Average), 나아가 5개 이상의 예측치를 Meta Feature로 삼는 Stacking 기법 적용.
4. **Probability Calibration**: Logistic Regression, Isotonic Regression 등을 통과시켜 예측 확률의 분포를 대회 특성에 맞게 자가 교정(Calibration).

> **AI 행동 원칙:** 사용자가 "다음 단계 진행해줘"라고 짧게 요청하더라도, AI는 이 문서를 확인한 뒤 스스로 `로그 분석 -> 목표 설정 -> 코드 작성 -> 학습 실행 -> 로그 업데이트 -> 다음 전략 수립`의 전체 루프를 매끄럽게 수행하여 실질적인 결과물(업데이트된 로그 파일과 스크립트)을 제시해야 합니다.
